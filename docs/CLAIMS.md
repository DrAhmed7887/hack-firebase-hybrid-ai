## Not claimed
- Any behaviour on real or non-seeded notes. For a pasted note the guard checks patterns only; names in prose are not checked, and review found names (accents, all-caps, "Surname, First") the rules can miss.
- Gemini Nano quality beyond the 3 saved desktop-Chrome runs in `docs/bench-nano-runs.json` (20 synthetic seeded notes each). Headless Chrome reported `LanguageModel.availability()` `unavailable` on 25 Nov 2026. CI never runs Nano: the tests use a perfect-detector test double, labelled as such, to check the pipeline logic only.
- Extraction accuracy beyond these runs: templated synthetic notes (20-note run and three 100-note runs) and one run on 50 PMC abstracts (46 of 50 correct against the single-reader audited key, 92.0%; 9 of 50 against the automatic key). The CI bench uses a MOCK regex backend, so its extraction output is not a model result and is not reported; the real-cloud figure above comes from the separate script.
- Any de-identification, privacy-compliance or clinical-performance claim. Prototype on synthetic data.
- Any time saving. Not measured.
