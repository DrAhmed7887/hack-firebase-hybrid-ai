## Not claimed
- Any behaviour on unreviewed hospital charts. For a pasted note without a seeded list the guard checks patterns only; names in prose are not checked, and held-out plus review checks confirm rules miss unlabelled prose names and `"Surname, First"` names (`Alvarez, Mateo`).
- Gemini Nano quality beyond the 3 saved desktop-Chrome runs in `docs/bench-nano-runs.json` (20 synthetic seeded notes each). Headless Chrome and `?rules-only` report Nano unavailable; CI never runs Nano (tests use a labelled test double to check pipeline logic only).
- Extraction accuracy beyond these runs: one audited run on 50 PMC abstracts (46 of 50 correct against the single-reader audited key, 92.0%; 9 of 50 against the automatic key) and templated synthetic notes (20-note run and 100-note runs). The CI bench uses a MOCK regex backend, so its extraction output is not a model result.
- Any de-identification, privacy-compliance or clinical-performance claim. Prototype on synthetic identifiers and public abstracts.
- Any time saving. Not measured.
